🧠 Why Practise Counting Objects?

Counting objects helps children connect number words and written numbers with actual quantities. It also gives them practice with one-to-one counting, number recognition and early mathematical thinking.

🍎 Start Counting

Encourage your child to touch or point to each object while saying one number for each object. Then ask which number shows how many they counted.

🎁 Start Counting 1–5

💡 Let Your Child Count Slowly

There is no need to rush. Encourage your child to touch each object once while counting. If they lose track, simply start again together and keep it fun.
